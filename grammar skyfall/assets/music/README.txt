GRAMMAR SKYFALL MUSIC SLOTS

Replace these files with your own MP3s. Keep the exact filenames:

menu.mp3      = home / lobby / setup
gameplay.mp3  = board / mini-games / vote / final ready
skyfall.mp3   = SKYFALL final
victory.mp3   = winner / draw
solo.mp3      = SOLO QUEST (normal solo challenges)
delpino.mp3   = DEL PINO CHALLENGE only

The included solo.mp3 and delpino.mp3 are silent placeholders so the paths
already exist. Replace those two files with your own music without changing code.

Missing music files never stop the game or its sound effects.
