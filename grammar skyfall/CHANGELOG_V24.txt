GRAMMAR SKYFALL — V24 FINAL

• Fixed a real 3–6 player crash found during the final smoke test: the mini-game was being rendered before its first question existed. V24 now creates the first mini question before rendering.
• Reworked final READY synchronization: online READY uses acknowledgement + automatic retry, so a missed packet cannot silently leave the 2-player Skyfall screen stuck on READY.
• Skyfall countdown is synchronized by the host before the falling cards begin.
• Skyfall question order is randomized per finalist and per level instead of always following the same sequence.
• Skyfall hints now show the base verb/form when the answer is a third-person Present Simple form (example: HE ___ WATER. (drink)).
• Added SOLO QUEST music slot: assets/music/solo.mp3.
• Added DEL PINO CHALLENGE music slot: assets/music/delpino.mp3.
• DEL PINO CHALLENGE remains separate from EASY / HARD / DIFFICULT; Speed Check is not inside Difficult.
• Added the missing board roulette handler so SPIN NUMBERS works in the test and live board.
• Longer roulette result and answer feedback timings were kept for presentation visibility.
• When exactly two survivors vote NO/NO to Skyfall, the match enters BOARD RACE mode: the first survivor to reach tile 40 wins immediately.
• A 1–1 YES/NO split has no majority, so the normal board continues.
• Back/home cleanup now clears dedicated Skyfall timers as well as general timers.
• Added a central WebSocket relay server in server/ so Render can host online rooms without PeerJS.
• Server supports 2–6 players total and enforces room capacity.
• Render deployment for a repository with project files at the root:
  Root Directory: blank
  Build Command: npm install --prefix server
  Start Command: node server/server.js
• If the project is inside a GitHub subfolder named “grammar skyfall”, set Render Root Directory to “grammar skyfall”.
• GitHub: extract the ZIP first. Render must see index.html, css/, js/, assets/ and server/ rather than a ZIP file by itself.
