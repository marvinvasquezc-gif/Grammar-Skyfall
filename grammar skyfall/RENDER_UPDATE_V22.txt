RENDER UPDATE — V22

Your current Render setup can stay the same if the repository still uses the folder named "grammar skyfall".

Root Directory:
grammar skyfall

Build Command:
npm install --prefix server

Start Command:
node server/server.js

GitHub update:
1. Replace the contents of the existing "grammar skyfall" folder with the V22 project contents.
2. Commit the changes.
3. Render will deploy the new commit automatically, or use Manual Deploy → Deploy latest commit.

IMPORTANT: Do not upload the ZIP as one file. Upload the project files/folders so that index.html and the server folder remain inside "grammar skyfall".
