GRAMMAR SKYFALL — V21 ONLINE SERVER + GAMEPLAY FIXES

This build uses a CENTRAL WebSocket multiplayer server. Netlify is optional for this version.

RECOMMENDED (one URL for everyone):
1) Deploy the whole project to a Node.js host that supports WebSockets (Render is the setup used for this project).
2) In Render, set Root Directory to:
   grammar skyfall
3) Build Command:
   npm install --prefix server
4) Start Command:
   node server/server.js
5) Deploy and open the public HTTPS URL from Render.
6) Host chooses CREATE ONLINE.
7) Friends choose JOIN WITH CODE and enter the 6-character room code.

The browser automatically uses the same-origin WebSocket endpoint:
   https://YOUR-DOMAIN/  ->  wss://YOUR-DOMAIN/ws

Health check:
   https://YOUR-DOMAIN/health
It should return JSON with ok:true.

NETLIFY:
Netlify can host a static copy, but the WebSocket server must remain on a separate WebSocket-capable Node service. In a Netlify frontend, set js/config.js to the secure server endpoint, for example:
   window.PSR_CONFIG={ relayUrl:'wss://your-server.example.com/ws' };

V21 FIXES INCLUDED:
- End-of-round elimination challenge now advances through 6 -> 5 -> 4 -> 3 -> 2 survivors.
- Lowest mini-game score is eliminated; tied lowest scores produce DRAW with nobody eliminated.
- Stale mini-game timers cannot advance a newer question.
- Online players can control only their own Farm, Mini, Vote, Ready, and Skyfall actions.
- Host can no longer type or answer for another connected player.
- Skyfall hints use the base-form clue, e.g. LOVES -> (love).
- Music ON/OFF is available throughout the normal UI, including the home screen and challenge overlays.
